# Reportar vulnerabilidades

Não inclua tokens, certificados, chaves HMAC, evidências reais ou dados pessoais em issues públicas.

Use o canal de relato privado de vulnerabilidades do GitHub, se habilitado no repositório. Caso não esteja disponível, contate o mantenedor pelo perfil GitHub para combinar um canal privado antes de divulgar detalhes exploráveis.

O projeto está em fase de piloto. Atualizações e correções devem ser acompanhadas antes de qualquer implantação. As limitações conhecidas estão em [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md), [docs/COVERAGE.md](docs/COVERAGE.md) e [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
